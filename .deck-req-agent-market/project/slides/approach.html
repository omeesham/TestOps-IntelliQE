The approach for API automation

How the Requirement Agent works — five moves

1

Ingest & correlate — pull the API spec and the related JIRA / ADO / BRD / FRD; align each endpoint to its intent.

2

Model the surface — derive resources, auth, pagination and cross-endpoint dependencies (resource graph).

3

Extract requirements — one source-linked record per endpoint: purpose, inputs, expected response, errors, NFRs.

4

Rank & populate — score by business risk, then auto-fill the traceability matrix for human review.

5

Hand off & re-run — feed the planner/generator; re-trigger on any spec or story change to stay current.

The approach is reuse-first: ingestion via existing connectors, the resource graph from api-intelligence, extraction via the LLM runner, persistence into the existing traceability UI. Steps 1–2 give the context spec-only tools lack; 3–4 produce the defensible output; 5 keeps it alive.
