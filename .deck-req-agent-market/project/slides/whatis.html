What the Requirement Agent is

The first stage that turns intent into a testable plan

It sits at the front of the pipeline. Before a single test is generated, it reads every source of truth and produces a structured, per-endpoint requirement set that the planner, generator and traceability matrix all build on.

INPUTS

API spec + JIRA / ADO / BRD / FRD

REQUIREMENT AGENT

Per-endpoint, risk-ranked, source-linked requirements

FEEDS

Planner → Generator → Traceability

Get this stage right and everything downstream inherits better coverage, correct priorities and built-in traceability. Get it wrong and the whole pipeline tests the wrong things faster.

Position the agent as the leverage point of the pipeline. Its output quality caps the quality of every later stage, which is why the market pain concentrates here and why it deserves dedicated features.
