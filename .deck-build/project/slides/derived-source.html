The source link is derived, never generated.

The model writes the purpose, the inputs, the expected responses and the rules. It is never asked where a requirement came from. That is built from the endpoint’s own import origin and its operation id, and matched back to the endpoint by position.

A model that is never asked for a Jira key cannot invent one. Traceability that would be worth nothing if it could be hallucinated stays worth something.

This was the single most important design call in Phase 1. Asking the model to fill in the source would have produced plausible-looking spec sections and issue keys with nothing behind them — exactly the failure mode that makes a traceability matrix untrustworthy.
