Four things only running it could find

Both type checks were clean before any of these showed up.

The silent drop

Starting a run clears the log, so the “held back” warning was wiped exactly when endpoints were really being dropped. Now a persistent banner the user has to dismiss.

POST POST /v1/orders

The endpoint title already carries the method, so the banner printed it twice. Caught and fixed without spending a single model call.

The flag that never showed

The environments store rebuilds each record field by field, so the new flag was saved, returned by the API, and then quietly dropped on the way to the screen.

The squeezed name

A third badge pushed the environment’s own name out of the card header. The badge became an icon; the footer button still says the state in words.

Worth saying out loud: a clean compile proved nothing about any of these. Three were only visible by driving the real UI, and the first one was invisible even then until the partial case was run deliberately.
