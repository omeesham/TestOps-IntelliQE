Four asks, three phases

The checklist What shipped Phase
Purpose, inputs, expected responses and business rules captured for every endpoint A Requirement Agent that writes one structured requirement per endpoint Phase 1
Each requirement links back to its source — a spec section or a Jira key A source link derived from the import origin, never written by the model Phase 1
A reviewer can edit or reject items before planning starts draft → approved or rejected, and the planner only ever sees approved Phase 2
The feature is tested and signed off in a customer-similar environment A sign-off record, and a release-gate check that can block the deploy Phase 3

All four are built, wired into the existing API Studio, and verified in the running stack.

Each phase was built and verified before the next one started, so at no point was there a half-wired feature sitting in the tree. Phase 1 backend first, then its UI, then the gate, then sign-off.
