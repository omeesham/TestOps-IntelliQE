A signer cannot wave a failing run through

The result on a sign-off is computed from the run it points at — no failures, nothing broken, and at least one test. The person signing supplies a note, not a verdict. All three branches were exercised live.

What was tried What was recorded What the gate said
The run was never signed off nothing FAIL — not signed off
A 79% run signed off as “UAT pass on customer-like data” fail (79%) FAIL — signed off failing
A 100% run signed off in the customer-similar environment pass (100%) PASS
The middle row is the one that matters. A sign-off is an attestation, and an attestation that lets you assert a result you did not get is worse than no attestation at all, because it looks like evidence.
