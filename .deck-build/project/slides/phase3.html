Phase 3

Signed off, somewhere that looks like production

Who, and when

The reviewer’s name, the moment they signed, and the note they left with it.

Where

The environment, and whether it was flagged customer-similar at that moment — a toggle that now lives on every environment card.

What the run did

The run it refers to, its pass rate, and the verdict the numbers give.

The environment name, its customer-similar flag and the pass rate are copied onto the record, not looked up later. Rename the environment or clear the flag tomorrow and yesterday’s attestation still says what was true when it was made.

Sign-off was added as one more check inside the release gate that already existed, rather than as a parallel gate. That gate already had policies, thresholds, a per-check table and a confidence score, so the new rule inherited all of it for the cost of one check.
