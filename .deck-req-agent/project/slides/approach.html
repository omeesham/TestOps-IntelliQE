The approach

Five steps — reuse, don’t rebuild

1

Schema — add an ApiEndpointRequirement type with a source field (state.ts).

2

Endpoint-aware agent — branch requirementAgent to emit one requirement per endpoint.

3

Auto-fill traceability — persist output as Requirement records in the matrix.

4

Source ingestion — wire JIRA / ADO / BRD / FRD text into the source field.

5

Sign-off — run end-to-end on a real API + Jira story in staging; check the 4 boxes.

Steps 3, 4 and 5 all depend on the output shape defined in steps 1 and 2 — so start there. Everything leans on existing code: the catalogue, the agent runner, and the traceability UI.
