What the ticket asks

Agent job (Notes)

“Reads the API definition and the related Jira story, and lists what must be tested for each endpoint.”

Definition of Done — the 4-item checklist

1 · Per-endpoint detail

For every endpoint: purpose, inputs, expected response (and errors).

2 · Traceability

Each requirement links back to its source (spec section / Jira story).

3 · Reviewable

A reviewer can confirm nothing is missing before testing starts.

4 · Signed off

Feature is tested & signed off in a customer-similar environment.

The ticket is a Microsoft Planner card. The checklist is the acceptance criteria / Definition of Done. Items 1 and 2 are the build work; 3 and 4 are review and sign-off gates.
